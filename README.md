# 😊 MOOD SLAY - Offline AI Face Mood Detector

**Live App:** https://chaitra-2006.github.io/face-scan1/

### What is it?
Offline AI app that scans your face with camera and tells mood - Happy, Sad, Angry, Calm, Surprised, Scared - in real-time. 100% private, no internet needed after load.

### Features
- 📸 Real-time face detection
- 😊 7 mood detection
- 🔒 100% offline & private - face never leaves phone
- 📱 PWA - Add to Home Screen

### Tech Used
- face-api.js (TensorFlow.js)
- GitHub Pages
- JavaScript, HTML5

### How to Use
1. Open Live App link
2. Click START CAMERA
3. Allow camera
4. See your mood!
